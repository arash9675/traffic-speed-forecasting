# Project Repository

This repository contains multiple models and implementations organized in separate folders.

## Getting Started

To access and use the models in this repository:

1. **Navigate to the specific folder** containing the model you want to use:
   - `Graphformer/` - Contains the Graphformer model implementation
   - `final_project_GNNpart/` - Contains the GNN project implementation

2. **Read the README file** inside each folder for detailed instructions on:
   - Model setup and installation requirements
   - How to execute the code
   - Usage examples and parameters
   - Dependencies and environment setup

## Usage Instructions

Each model folder contains its own comprehensive README with specific execution instructions. Please refer to the individual README files for:

- Installation steps
- Required dependencies
- Execution commands
- Configuration options
- Example usage

## Support

For model-specific questions or issues, please refer to the documentation within each respective folder.
